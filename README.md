# 奶辰模拟器

奶辰的金融社牛大学生活模拟器！

## 🚀 部署到Vercel（推荐）

1. 注册Vercel账号：https://vercel.com
2. 安装Vercel CLI：
   ```bash
   npm install -g vercel
   ```
3. 在项目目录运行：
   ```bash
   vercel
   ```
4. 按提示登录和部署
5. 完成后会得到一个网址，手机电脑都能访问！

## 📱 其他部署方案

### Netlify（也是免费）
1. 注册：https://www.netlify.com
2. 拖拽整个项目文件夹到Netlify
3. 构建命令：`npm run build`
4. 发布目录：`dist`

### GitHub Pages
1. 把项目推送到GitHub
2. 在仓库设置里开启GitHub Pages
3. 选择部署分支

## 🎮 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3002
